# Lista de Tarefas

App de exemplo (Node.js + Express + EJS) usado para demonstrar a
[Fábrica de Software Agêntica no Claude Code](https://github.com/mateusscs/fabrica-agentica-claude-code).

```bash
npm install
npm start      # http://localhost:3000
npm test
```

As novas funcionalidades deste repositório são especificadas, planejadas, implementadas, revisadas e testadas
pelos agentes da fábrica, e chegam à branch `main` por pull request aprovado por um humano.
